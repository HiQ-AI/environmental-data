# 中国锂电池碳足迹数据查询（CESI）

Use the bundled [CESI Data Querying](skills/cesi-query/SKILL.md) skill for requirement clarification, candidate discovery, matching and authorized detail retrieval.

Program: `cesi`, version 0.7.5. Business commands: `search` and `lookup`. Compiled source/publisher limits and server entitlements remain authoritative. Plugin installation does not install a binary or grant credentials.

See the repository installation and migration notes before upgrading. Never overwrite an unrelated same-name command. Windows installer acceptance is reported separately from native executable checks.
