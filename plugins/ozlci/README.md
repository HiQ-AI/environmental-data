# OzLCI 数据查询

Use the bundled [OzLCI Data Querying](skills/ozlci-query/SKILL.md) skill for requirement clarification, candidate discovery, matching and authorized detail retrieval.

Program: `ozlci`, version 0.7.5. Business commands: `search` and `lookup`. Compiled source/publisher limits and server entitlements remain authoritative. Plugin installation does not install a binary or grant credentials.

See the repository installation and migration notes before upgrading. Never overwrite an unrelated same-name command. Windows installer acceptance is reported separately from native executable checks.
